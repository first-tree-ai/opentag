# Web i18n

[简体中文](./zh-CN/i18n.md)

OpenTag Web uses Paraglide JS 2.25.0 with English (`en`) as the base locale and Simplified Chinese (`zh`) as the
second locale. The locale strategy is `localStorage`, then the browser preferred language, then `baseLocale`. A first
visit follows `Accept-Language`; an explicit choice is persisted in the `PARAGLIDE_LOCALE` local-storage key. Locale is
not part of the URL. This keeps authenticated routes and deep links stable, but gives up locale-specific URLs and SEO
for public pages. `setLocale()` reloads the document so the HTML language and direction are applied consistently.

## Message files and ownership

Messages live in `apps/web/messages/<area>/{en,zh}.json`. Keys use the `<area>_<surface>_<slot>` convention: lower-case
snake case, with the area prefix matching the directory (`agent-settings` becomes `agent_settings`). The `common_`
catalogue is frozen after the foundation lane. If a later lane needs a shared word that is not already present, it owns
a duplicate key in its own area.

The file that emits the final visible string owns the message. A helper may provide a label, but a template that combines
that label with other text belongs to the area that renders the template. This keeps lane ownership explicit and avoids
cross-area key collisions.

## Messages and Intl

Use Paraglide messages for sentences, punctuation, grammar, and plural wording. Use the locale-aware helpers in
`src/i18n/format.ts` for dates, day/month labels, numbers, compact numbers, collation, and case folding. The helpers map
`zh` to the `zh-CN` Intl locale and `en` to `en-US`. Do not replace the English relative-time sentences with
`Intl.RelativeTimeFormat` automatic wording: OpenTag intentionally says “just now” and “1 day ago”.

Chinese punctuation has no leading ASCII spaces. Keep the ASCII `·` separator and the `…` character. Never translate or
rename `{placeholder}` names.

The following English leakage is accepted: English strings owned by Kumo components (Kumo exposes no locale API),
`ApiError.message` values returned by the server, and Zod validation messages from `packages/shared`.

Keep `<title>OpenTag</title>` in `apps/web/index.html` exactly as written. The `container-smoke` check searches for that
literal and the product name is not translatable.

## Tooling rule

> **Never run `inlang machine translate` or Sherlock's extract on this project.** Under an array `pathPattern`, every
> inlang write flow serializes the merged catalogue into every file in the array, duplicating all keys across all areas.
> Compiling is safe because it uses `skipExporting: true`; Chinese messages are authored by hand.

The 16 message areas are owned by the foundation plus the Wave 2 lanes: `common` and `format` belong to Wave 1;
`shell`, `errors`, `auth`, `account`, `agents`, `agent-settings`, `agent-create`, `tasks`, `usage`, `skills`,
`integrations`, `onboarding`, `onboarding-v2`, and `im` are owned by their named migration lanes. Generated
`src/paraglide/` output is ignored and must never be edited or committed.
