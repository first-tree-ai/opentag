# Skill 阅读器浏览器验证

[English](README.md)

同步日期：2026-10-16。

阅读器及历史导入与发现截图采集于 2026-10-10，通过 Playwright 在有界面的 Chrome 中验证，使用生产代码中的 `SkillsPage` 和阅读器组件，启用 React StrictMode。
仓库外的临时 Vite 入口提供内存中的模拟 API 响应。截图来自实际交互界面，不是静态设计图；它们不代表连接真实
PostgreSQL 和存储服务的端到端测试。后端另有认证路由、服务测试和真实 tar.gz 测试包验证。
下方历史导入入口和发现与导入入口截图使用同一模拟入口，在 Codex 内嵌浏览器中采集。早期阅读器截图仍保留旧按钮文案；历史发现截图中的入口现已隐藏。

## 行操作居中（2026-10-16）

宽内容区内，开关与更多菜单相对于“名称＋描述”整体垂直居中，保留原有水平间距和右侧留白。窄内容区内，操作组
仍在名称轨道内居中，单行描述放在下方，避免长名称或描述与操作区重叠。

复用生产组件预览并加载当前模块样式，在 320px、390px、768px 和 1440px 下测量，确认相应的中心对齐、文字与操作区
互不挤占，且页面没有横向溢出。开关与更多菜单保持独立；Enter 打开详情，Escape 关闭。320px 和 1440px 列表的 axe
扫描均无违规。本次未新增可复用组件、主题值或 CSS 例外。

## 紧凑列表描述（2026-10-16）

所有宽度下的 Skill 列表描述均保持单行，移除描述浮层和名称的原生 title 提示。悬停或键盘聚焦时，原有详情点击区域内
显示箭头。阅读器在可滚动的阅读区域中、文件内容上方展示完整描述。每行隔离层叠上下文，避免独立的开关和更多菜单
绘制到阅读器弹窗上方。

截图来自使用生产组件和 OpenTag 主题的临时构建预览，在 Codex 内嵌浏览器中以模拟的内存 API 响应验证。
320px、390px、768px 和 1440px 下均无横向溢出，描述保持单行。坐标点击描述能打开详情，开关与更多菜单保持独立。
Shift+Tab 显示详情入口的焦点轮廓和箭头，Enter 打开阅读器，关闭后焦点返回入口。本次未新增 axe 扫描、可复用组件、
主题值或 CSS 例外。

## 空状态优化（2026-10-12）

技能空列表直接融入页面背景，使用 32px 文档图标、18px 语义化标题及 14px 导入说明。文案和页头唯一的导入菜单
保留现有行为。截图来自使用生产组件及主题的临时构建预览，API 返回内存中的模拟数据；不代表真实存储或服务验证。

浏览器检查覆盖 320px、390px、768px 和 1440px，均无横向溢出。Tab 和 Enter 能打开导入菜单及链接安装弹窗，
Escape 关闭弹窗并将焦点返回导入技能按钮。同时检查了有技能的列表，以及存储不可用时禁用导入的状态。
本次未新增 axe 扫描、可复用组件、主题值或 CSS 例外。

## 已执行的检查

- 名称、描述和内容区留白通过同一个原生按钮打开详情。实际坐标点击描述及内容区远端留白均通过；开关和更多菜单
  独立工作，不会打开详情。Enter 和空格打开阅读器，Escape 返回入口焦点；320px 和 390px 入口均无横向溢出。
- 名称为 16px/600，描述为 14px。1440px 和 768px 下，操作相对于“名称＋描述”整体居中；390px、320px 及桌面窄内容区
  中，操作与名称居中对齐；手机描述在名称和操作下方占满内容宽度。
- 2026-10-16 之前的历史浮层验证：描述提示仅在文本实际截断时出现。长描述在 320px 下显示提示，悬停时扩宽至 1440px 后自动消失；完整描述不弹提示。
  ResizeObserver 和字体加载事件保持测量准确。
- 广场体验设计期间，页头和空状态暂时隐藏「技能广场」。仅保留描边的「导入技能」菜单，提供「从链接安装」和
  「上传文件」。空状态说明两种导入方式，不重复按钮。内嵌浏览器验证了中英文菜单、链接安装弹窗入口和 320px
  空状态布局，页面宽度保持为 320px。现有技能库组件与接口保留，供后续接回。

- 四种视口宽度的 axe 检查均无违规；页面没有横向溢出，弹窗完全位于视口内。手机使用文件选择器。
- 阅读完整 Markdown、Frontmatter 和 Source，访问首屏之后的正文。单文件阅读器中，聚焦正文后 PageDown 能滚动。
- 打开参考 Markdown，通过包内相对链接返回 `SKILL.md`，焦点移至新正文区域。脚本始终作为字面文本展示，包括类似
  script 标签的内容。
- 检查二进制文件、超大文件提示、手机文件切换和临时失败时的重试状态。
- Escape 关闭并将焦点返回 Skill 详情入口按钮；Enter 重新打开。连续二十次 Tab 始终保持在弹窗内。文件夹和文件按钮采用
  常规键盘操作。
