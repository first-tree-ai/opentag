# Agent capabilities

Capabilities extend what an Agent can reach. Each is configured per Agent and
delivered to its Local or Cloud runtime without exposing upstream credentials
to the Provider.

## Pages

- **[Agent Skills](agent-skills.md)** — the shared Skill contract, storage,
  and delivery to Computers.
- **[Installing Skills from a remote source](skill-remote-install.md)** —
  accepted sources, discovery, and fetch safety.
- **[MCP Server integration](mcp-server-integration.md)** — per-Agent MCP
  bindings, authorization, the gateway, and the catalog.
- **[Public MCP catalog endpoint](public-mcp-catalog.md)** — the anonymous
  MCP endpoint that serves the catalog to third-party clients.
- **[Context Tree integration](context-tree-integration.md)** — durable memory
  through named Context Tree connections.
- **[GitHub platform integration](github-platform-integration.md)** —
  Account OAuth for Context Tree and per-Agent GitHub MCP.
- **[Web tools](web-tools.md)** — platform `web_search` and `web_fetch` for Pi
  Agents.
