# Soul content editorial review

Soul describes durable behavior: role, judgment, working habits, delivery expectations, and communication. Task-specific
execution details belong in the request or a Skill. Brevity is useful when it removes repetition; it must not erase the
observable habits that distinguish these roles.

The catalog retains a moderate body and four consistent headings: Role and purpose, Working approach, Deliverables,
and Communication style. The Chinese headings are 角色与目标、工作方式、交付要求、沟通风格. These are part of the actual
editable body, not additional UI metadata.

| Template | Preserved distinction | Editorial adjustment |
| --- | --- | --- |
| Engineering | Evidence before changes, root-cause diagnosis, focused scope, final review, actionable findings, honest verification | Shortened the introductory persona and repeated scope wording; consolidated trade-off communication. |
| Design | Task hierarchy before polish, suitable component reuse, interaction states, responsive and accessible behavior, rendered review | Shortened abstract qualities and overlapping descriptions of action states. |
| Product | Build/investigate/defer/stop decisions, non-goals, coherent release scope, proportionate learning | Removed repeated reconsideration instructions; small questions explicitly permit direct answers. |
| Research | Original sources, independent evidence, circular citation checks, counterevidence, thematic synthesis, disclosed coverage | Removed repeated skepticism, comparison, and research-scope statements while preserving their concrete requirements. |
| Writing | Reader prerequisites, structure before sentence polish, errors versus preferences, intended voice, usable copy | Kept respect for voice in the role definition and removed repeated voice directives elsewhere. |
| Data Analysis | Metric definitions, denominator and data quality checks, reproducible calculations, causality, practical significance | Removed repeated definition checks from the introduction; time boundaries and preparation checks have explicit applicability. |
| Growth | Funnel bottleneck, acquisition economics and retention, downstream quality, experiments with guardrails and decisions | Consolidated opportunity evaluation and repeated next-decision wording; retained the conditional experiment requirements. |
| Operations | Confirmed versus proposed commitments, process diagnosis, baseline verification, SOP exceptions, actual tool execution | Consolidated ownership, handoff, and missing-information wording; retained the boundary against unarranged monitoring. |

The list summary and applicability overview remain separate from the body. Only the body is inserted. No hard word
limit is imposed, and shorter content does not claim better agent performance. Runtime effectiveness still needs
evaluation on representative tasks.

## Reading structure

The same moderate bodies use paragraphs for role and communication, three or four flat bullets for working approach,
and two bullets for deliverables. Parallel expectations are easier to scan without adding another level of headings.
This restructuring preserves the original wording and sequence in both languages. Preview and editing share the same
document typography; users can add paragraphs, headings, and lists with the same presentation. Existing saved Soul text
is not automatically restructured.
