# Discover 分类与初始焦点

[English](./README.md)

同步日期：2026-10-13。

Discover 打开时焦点位于标题。账户目录加载完成后，不会将焦点移到搜索框或打断用户的键盘导航。

目录按文档与知识、沟通、项目管理、网页搜索、设计、数据分析和开发工具分组。销售与客户、财务支付和工作流自动化目前各有一个连接器，因此暂时隐藏分类入口。全部 26 个连接器仍可通过“全部”和搜索找到。分类在完整目录中至少有两个条目时显示入口，不受搜索结果或连接状态影响。恢复弹窗时，已失去可见入口的分类回退到“全部”。

桌面使用紧凑的分类按钮。宽度不超过 600px 时，改用分类选择器，为连接器列表留出更多空间。两种控件共享分类选择和搜索行为。

## 验证

现有 Playwright Discover 授权套件的八项流程通过，覆盖 1440px、736px 和 320px。验证包括打开时的标题焦点、分类切换、OAuth 完成、取消、重试、弹窗被拦截后的恢复、筛选期间的独立授权、卡片尺寸稳定和页面无横向溢出。桌面授权流程也通过套件的自动无障碍扫描。390px、768px 和中文浏览器渲染未单独检查。
