# Skill details reader: verification and acceptance

Test and acceptance material for [Skill details reader](../../docs/system/web/skill-details-reader.md).

## Validation

Unit coverage exercises real tar.gz fixtures, complete indexes beyond 500 entries, ownership, canonical paths, stale
hashes, corruption, decompression limits, binary/large/empty text, Markdown injection, navigation and delayed Agent reads.
Browser evidence and exact checks are recorded in [the UI evidence](../web-ui/skill-reader/README.md).
