下方当前导入入口和历史发现与导入入口截图使用同一模拟入口，在 Codex 内嵌浏览器中采集。早期阅读器截图仍保留旧按钮文案；历史发现截图中的入口现已隐藏。

## 已执行的检查

- 名称、描述和内容区留白通过同一个原生按钮打开详情。实际坐标点击描述及内容区远端留白均通过；开关和更多菜单
  独立工作，不会打开详情。Enter 和空格打开阅读器，Escape 返回入口焦点；320px 和 390px 入口均无横向溢出。
- 名称为 16px/600，描述为 14px。在 1440px、768px、390px、320px 及桌面窄内容区中，操作与名称对齐；手机描述在
  名称和操作下方占满内容宽度。
- 描述提示仅在文本实际截断时出现。长描述在 320px 下显示提示，悬停时扩宽至 1440px 后自动消失；完整描述不弹提示。
  ResizeObserver 和字体加载事件保持测量准确。
- 广场体验设计期间，页头和空状态暂时隐藏「技能广场」。仅保留描边的「导入技能」菜单，提供「从链接安装」和
  「上传文件」。空状态说明两种导入方式，不重复按钮。内嵌浏览器验证了中英文菜单、链接安装弹窗入口和 320px
  空状态布局，页面宽度保持为 320px。现有技能库组件与接口保留，供后续接回。

- 四种视口宽度的 axe 检查均无违规；页面没有横向溢出，弹窗完全位于视口内。手机使用文件选择器。
- 阅读完整 Markdown、Frontmatter 和 Source，访问首屏之后的正文。单文件阅读器中，聚焦正文后 PageDown 能滚动。
- 打开参考 Markdown，通过包内相对链接返回 `SKILL.md`，焦点移至新正文区域。脚本始终作为字面文本展示，包括类似
  script 标签的内容。
- 检查二进制文件、超大文件提示、手机文件切换和临时失败时的重试状态。
- Escape 关闭并将焦点返回 Skill 详情入口按钮；Enter 重新打开。连续二十次 Tab 始终保持在弹窗内。文件夹和文件按钮采用
  常规键盘操作。
