# OpenTag 应用设计指南

英文规范：[design.md](../../design.md)。本文同步于 2026-09-28。
已选择 **概念 1 — Quiet Workspace**。应用应是简洁、克制的工作工具。
每条信息都应帮助用户选择 Agent、理解状态、查看工作或完成配置。

## 实现与规范来源

保留 Kumo，通过产品适配层统一样式与行为。迁移到 shadcn 并不能自动保证组合一致性，
目前不替换已验证的控件。只有出现适配层无法满足的明确需求时才重新评估。

- `apps/web/src/ui/design.tokens.ts`：颜色与尺寸的唯一配置来源。
- `apps/web/src/ui/theme.css`：生成的主题与 Kumo 语义变量映射。
- `apps/web/src/ui/primitives.css`：文字、按钮、表单控件、面板和对话框样式。
- `apps/web/src/ui/design-system.tsx`：产品语义、标签、ref、状态与兼容行为。
- `apps/web/src/app.css`：字体加载、浏览器默认值与应用布局。
- `docs/design/web-ui-contract.md`：组合、交互、无障碍与验证规则。
- `apps/web/src/ui/KUMO.md`：Kumo 实现说明。

修改 tokens 后运行 `pnpm theme:generate`，同时提交生成的 CSS。
`pnpm check` 会检查生成结果是否同步。页面通过适配层使用控件，
不直接导入 Kumo，不重复添加页面级控件样式。

## 视觉规则

网站的奶油白背景、白色面板、深色文字、紫色操作、Manrope 字体和现有猫标识延续到应用。
营销布局、标语、大标题、装饰色块和悬浮卡片不进入日常工具界面。

| 用途 | 浅色值 |
| --- | --- |
| 背景 | `#fffcf7` |
| 面板 | `#ffffff` |
| 正文 / 次要文字 / 弱化文字 | `#171719` / `#4c4d5c` / `#6b6674` |
| 操作 / 悬停 / 按下 | `#5638d8` / `#452bb5` / `#38218f` |
| 选中 | `#f1ebff` |
| 分隔线 / 控件边界 | `#e5e0db` / `#8c8795` |
| 内嵌区域 / 中性悬停 | `#f4f0e9` / `#f5f1eb` |

紫色表示操作和选择，不代替成功、警告、失败或工作状态。Ready 与 Working 活动仍是两个维度。
保留 lime 猫标识和用户头像；供应商标识使用其自身颜色。
浅色是正式支持的主题，深色值仅作兼容用途。门户控件继承根元素的命名空间主题属性。

使用自托管 Manrope 400/500/600/700；命令与日志使用等宽字体。
字体必须作为同源文件输出；Vite 不内联为 data URL，以符合服务端内容安全策略。
页面标题为桌面 28px、移动 24px，字重 600；章节 18px；小节 16px；正文与控件 14px；
元信息 12px；品牌字标 19px/700。每页一个语义标题，通过 PageHeader 放置标题和操作。

间距采用 4px 网格：章节间 24px，面板内 16–24px，列表行上下 16px、左右 16–20px，
行内 8–12px。内容最大宽度 1024px；桌面页边距 32px，移动 16px。
常规控件高 40px，桌面紧凑控件 32px，移动触摸目标至少 44px。
控件圆角 8px，分组面板 12px，对话框 16px。按钮为纯色；普通面板不使用悬停抬升，
菜单与对话框可使用轻微阴影。

## 页面组合

工作区采用全高 72px 导航栏，标识与 Home 在上方，Account 在底部。
进入 Agent 后导航扩展为 240px，显示切换器、章节与设置。
移动端使用紧凑页头和 Agent 抽屉。切换布局时保留页面和未保存输入。

| 页面 | 核心组合 |
| --- | --- |
| All Agents | 小标题、New Agent、数量、白色分组列表。头像、名称、消息供应商、就绪/活动状态及必要的继续配置入口。使用量保留在概览和 Usage。 |
| Agent 概览 | 身份、状态、依赖/就绪信息、已有使用量、最近任务及相关能力。 |
| Tasks / 详情 | 紧凑筛选，桌面列表与移动堆叠。保留来源、标题、状态、活动、取消、分页和重试。详情以对话/活动时间线为主，保留回复、附件和日志。 |
| Usage | 时间范围、总量、原有图表/表格，不新增宣传统计或重复摘要。 |
| Context Tree | 连接身份与状态，相关操作；命令使用中性内嵌面板。 |
| MCP / Skills / 集成 | 分组行、简洁身份与状态，必要操作；共用表单与对话框。 |
| Agent 设置 | 分组配置，短标签、必要提示、字段错误；区分执行、指令、模型、消息与破坏性管理。 |
| Account / Computer | 简洁配置及连接信息；保留账户菜单的全部入口。 |
| 登录 | 小型居中表单、品牌、登录供应商、语言和必要反馈，无启动宣传画面。 |
| 设置引导 | 任务步骤与紧凑选项，保留检查/修复、稳定高度、二维码、复制、过期与验证行为。 |
| 内部工具 / 预览 | 同一主题、字体、控件；模拟控制与预览分开。 |
| 空白 / 加载 / 错误 / 未找到 | 简短解释和下一步；保留加载、重试、输入与焦点。 |

省略不存在的可选元信息；不要为了截图显得空而删掉必要状态或操作。
新增信息前确认它帮助什么决策，以及是否已在同一页面显示。
每个任务上下文默认一个主要操作，其余使用次要或 ghost 样式。
破坏性操作保留确认和忙碌保护。保留字段标签关联、键盘焦点、Escape、焦点返回和本地化文案。

## 变更检查

1. 优先复用现有页面组合与控件。
2. 将共享样式写入 tokens/recipes；长期例外同步本指南。
3. 保留路由、归属、本地化文案、状态与键盘行为。
4. 检查 320、390、768、1440px，长表格/日志在局部滚动。
5. 验证受影响的页面测试、主题/适配层合同及浏览器无障碍与交互。
6. 提交前运行 `pnpm check`；PR 遵循仓库完整验证要求。

正文对比度至少 4.5:1，控件和焦点至少 3:1。
概念图仅记录选定方向，不能代替规范；图片中的大标题、光泽按钮、样例头像和数据
不作为生产实现要求。以英文指南、真实数据和紧凑纯色实现为准。
