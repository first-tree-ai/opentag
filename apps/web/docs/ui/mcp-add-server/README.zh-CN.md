# 自定义连接器安装

自定义连接器保留独立的“自定义”入口。首次请求前，表单展示连接器地址和认证方式，默认选择
“账号授权”，另有“API key 或 token”和“无需认证”。Key 方式只显示一个密码输入框。

高级设置默认折叠。认证请求头和前缀只用于 Key，默认值为 authorization 和 Bearer，允许空前缀。
所有方式均可配置额外请求头。名称自动生成。主按钮为“连接”；未提交的表单通过 X 或 Escape 关闭，
页脚不重复提供“取消”。

认证方式由用户明确选择，请求被拒绝后不会自动切换。提交通过现有定义、绑定和授权接口保存配置。
失败后保留输入和已提交配置；成功返回空工具列表也视为完成。

明确点击 OAuth“取消”只取消本次已发起的授权。首次添加流程拥有的安装会被删除，已经成功写入的
凭证则优先保留。关闭界面不会取消已提交的授权。不引入候选凭证、备份、回滚、数据库字段或迁移。
授权 DELETE 接口增加可选的 expectedOAuthState，用于条件取消；现有不带请求体的内部调用保持有效。

Discover 和自定义入口均创建独立定义；当前 Agent 已安装的连接器会被定位，而非重复安装。
历史共享模型的完整迁移不在本次范围内。
