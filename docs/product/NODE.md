# Product

Product decisions define what people see and do: how they work with Agents in
IM, what the Account owner can inspect, and what the hosted Cloud offering
provides.

- **[Cloud Computer](cloud-computer.md)** — Cloud as an Account-owned logical
  Computer and its resource controls.
- **[Cloud billing](cloud-billing.md)** — attribution, pricing, credits, and

- **[Doctor](doctor.md)** — the `opentag doctor` product specification.
- **[Trademarks](trademarks.md)** — third-party marks and openTag's own mark.
