# 连接器管理

列表右侧保留两行：第一行为启用开关和更多菜单，第二行为简短原因及恢复操作。
成功的工具快照不显示 Connected、成功圆点或工具数量。停用只通过开关表达。
点击名称或图标打开详情；菜单仅包含“详情”和“删除”。紧凑的删除确认框在“删除 {name}？”下方
展示“删除后，此 Agent 需要重新添加 {name} 才能使用。”右下角并排展示“取消 / 删除”，初始焦点位于“取消”。
不重复展示关闭按钮，Esc 仍可取消。
删除当前 Agent 的安装和无人使用的定义；仍被其他 Agent 使用的历史定义保留。

提示只表达已知事实：授权已失效、授权失败、无法访问服务、请求超时或无法加载工具。
更具体的凭证拒绝或授权撤销文案必须有服务端明确证据，内部 revoked 状态本身不代表服务方撤销。
认证恢复使用“授权 / 重新授权”，工具加载使用“重试”。完整空结果显示“暂无可用工具”，不提供重试；
部分结果继续使用。不提供错误浮层，也不展示原始上游错误。

Discover 保持原有卡片布局。进度或错误替换描述，操作仍在原位置。完成后恢复描述，原操作位置只显示
灰色勾号，并提供无障碍“已添加”标签。保留搜索、分类、滚动位置和打开的目录。
关闭目录不打断 OAuth；明确的“取消”和弹窗受阻后的“打开”仍在卡片内。
OAuth 授权过程中仍可关闭目录。列表与目录读取同一次操作，关闭后保留“授权中”和“取消”，
随后原位显示工具加载进度或失败原因。重新打开目录仍保留失败提示，直到重试；
目录中的授权仍在进行时，同一个连接器不能再发起一次授权。

预设详情包含名称、图标、关闭按钮、可见且可复制的连接器地址及认证区。
账号授权使用“授权 / 重新授权”；已保存的 API key 或 token 以掩码展示，提供“更新”，编辑时为
“保存 / 取消”。配置了多种方式的预设提供“使用 API key 或 token / 使用账号授权”；
选择其他方式只修改本地草稿，提交才生效。切换到 OAuth 使用“授权”。
不展示工具、高级设置、删除、清除凭证及全局保存页脚。自定义详情保留可编辑配置和高级设置。

详情中的 OAuth 提示与“授权 / 重新授权”同行，位于切换认证方式入口之前；窄屏时换到操作下方。
编辑认证失败的提示保留在认证字段旁。URL 校验位于输入框下方，连接或配置保存失败位于表单提交操作旁。
Discover 的凭证表单仅保留“取消 / 保存”，错误以简短红字展示在 Key 下方；目录仍保留关闭按钮和卡片内提示。

预设默认方式、备用 Key 地址及请求头规则维护在 packages/mcp-presets/mcp-catalog.yaml，
由生成器校验并输出公开注册表，不自动改写已安装配置。
提交直接替换已保存配置，不增加候选验证、备份或回滚。OAuth 成功后即使工具加载失败也保留凭证，支持重试。
已有有效授权时，从列表或目录重试工具加载不会打开授权窗口。
OAuth 完成后立即刷新授权数据，从详情页发起的授权也不必等待下一次轮询。
重试使用最新确认的授权状态。认证方式切换失败后保留预设表单和已提交配置。
凭证写入期间禁用可编辑字段；授权过程中的“取消 / 打开”仍可操作。

浏览器旅程使用虚构服务响应，不代表实际验证了官方授权或平台客户端接入。
