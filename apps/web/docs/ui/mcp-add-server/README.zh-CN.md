# Web 中的独立连接器安装

自定义添加仅包含 URL 和连接。通过右上角关闭按钮或 Esc 关闭弹窗，底部不再显示分隔线和重复的取消按钮。
Discover 和自定义添加通过现有管理 API，为每个 Agent
创建独立的后台定义。账号配置不再可选，相同 URL 不会触发跨 Agent 复用。当前 Agent 的已有
安装仍可定位、连接和重试。

名称自动生成。先尝试基础名称，仅在名称冲突后读取账号名称并有限次追加数字后缀。
已知目录安装在卡片和弹窗中统一显示本地化服务名称，自定义名称保持原样。不修改 schema 或
API；历史共享挂载和未挂载定义仍留在后台。

URL 弹窗高度为 216px，不等待账号配置池。URL 标签仅供读屏访问，输入框通过本地化占位提示引导输入，
打开时直接聚焦地址输入框。精确匹配的预设需要密钥时，桌面扩展到 304px，窄屏扩展到 320px。
OAuth 返回处理和临时挂载清理保持现有行为。

`e2e/tests/mcp-add.spec.ts` 验证独立安装、当前 Agent 重复添加防护、URL 校验、取消和重试、
登录错误、紧凑布局、键盘焦点、中文文案和可访问性。使用构建后的应用及虚构 MCP 响应，
不授权真实服务账号。单元测试另行覆盖密钥输入和并发名称冲突。
