# Web 国际化

> Canonical source: [../i18n.md](../i18n.md)
> Last synced with: 2026-09-01

OpenTag Web 使用 Paraglide JS 2.25.0，英文（`en`）为基础语言，简体中文（`zh`）为第二种语言。语言策略依次为
`localStorage`、浏览器首选语言和 `baseLocale`。首次访问遵循 `Accept-Language`；用户明确选择后写入
`PARAGLIDE_LOCALE` local-storage key。语言不进入 URL。这样可以保持鉴权路由和深链稳定，但放弃了按语言区分的
URL 以及公共页面的 SEO 价值。`setLocale()` 会重新加载文档，以便一致地设置 HTML 的语言和文字方向。

## 消息文件与归属

消息位于 `apps/web/messages/<area>/{en,zh}.json`。Key 采用 `<area>_<surface>_<slot>` 约定：小写 snake case，
且 area 前缀必须与目录一致（`agent-settings` 写作 `agent_settings`）。基础设施 lane 完成后，`common_` 目录冻结。
后续 lane 若需要尚未存在的通用词，应在自己的 area 中创建重复 key。

谁产出最终可见字符串，谁拥有该消息。Helper 可以提供 label，但把 label 与其他文字组合的模板属于实际渲染模板的
area。这样可以明确 lane 归属并避免跨区域 key 冲突。

## 消息与 Intl 的分工

句子、标点、语法和复数措辞使用 Paraglide 消息。日期、日/月标签、数字、紧凑数字、排序和大小写折叠使用
`src/i18n/format.ts` 中的 locale-aware helpers。Helper 将 `zh` 映射到 `zh-CN`，将 `en` 映射到 `en-US`。不要用
`Intl.RelativeTimeFormat` 的自动措辞替换英文相对时间：OpenTag 有意使用 “just now” 和 “1 day ago”。

中文标点前不加 ASCII 空格。保留 ASCII `·` 分隔符和 `…` 字符。绝不翻译或重命名 `{placeholder}` 名称。

中文在汉字与拉丁文之间留一个空格，汉字之间不留。当一个占位符可能收到两种文字时——`{provider}` 在一个分支里是飞书，在下一个分支里是 Slack——空格既不能写进词条，也不能写进标签，因为二者都不知道最终是哪两种文字相邻。这种词条在占位符两侧不写空格，改为把拼好的整句交给 `spaceBrandInSentence`。只可能收到一种文字的占位符照常在词条里自己带空格。

以下英文残留是接受的：Kumo 组件自带的英文（Kumo 没有暴露 locale API）、服务端返回的 `ApiError.message`，以及
`packages/shared` 的 Zod 校验消息。

保持 `apps/web/index.html` 中的 `<title>OpenTag</title>` 完全不变。`container-smoke` 会搜索这个字面量，产品名不可翻译。

## 工具规则

> **绝不在本项目运行 `inlang machine translate` 或 Sherlock 的 extract。** 在数组 `pathPattern` 下，所有 inlang
> 写入流程都会把合并后的完整目录序列化到数组中的每个文件，导致所有 area 重复全部 key。编译是安全的，因为它使用
> `skipExporting: true`；中文消息必须手工编写。

16 个消息 area 由 foundation 和 Wave 2 lanes 负责：Wave 1 负责 `common` 与 `format`；`shell`、`errors`、`auth`、
`account`、`agents`、`agent-settings`、`agent-create`、`tasks`、`usage`、`skills`、`integrations`、`onboarding`、
`onboarding-v2` 和 `im` 由对应名称的迁移 lane 负责。生成的 `src/paraglide/` 目录被忽略，绝不手动编辑或提交。
