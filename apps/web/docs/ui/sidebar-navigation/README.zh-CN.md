# 侧栏导航评审

更新日期：2026-10-12。

[English](README.md)

导航使用任务清单、指纹、大脑、错位技能模块和单插头图标。
技能排在连接器前面，所有入口保持连续列表。导航图标统一为 18px regular，行高为 44px，
项间距为 4px。全部 Agent、Agent 切换器和导航列表的图标与文字统一对齐，
这三块之间保留 16px 留白。选中时图标与文字一起使用选中颜色。

没有访问登录后的 API 或外部模型服务。

已检查中英文在 320、390、768、1440px 下的布局，没有页面横向溢出。
浏览器检查覆盖尺寸、对齐、项目顺序、选中颜色、Escape 与焦点返回、长 Agent 名称、
切换 Agent 时保留当前页面，以及保持原有 `/mcp` 入口。
