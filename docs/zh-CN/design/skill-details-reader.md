# Skill 详情阅读器

[English](../../design/skill-details-reader.md)

同步日期：2026-10-10。

Skill 摘要不能代替完整指令。点击已安装 Skill 的内容区，包括名称、描述及周围留白，即可阅读 `SKILL.md` 全文并切换
包内相关文件，无须离开管理页。阅读器衔接 PR #820 已合入的管理页布局，以扩展原生名称按钮的点击范围承载详情入口；
开关和更多菜单位于此区域之外，继续独立提供管理操作。内容区仅增加轻微悬停底色和清晰键盘焦点边框，不增加详情按钮。

## 阅读体验

大尺寸可关闭弹窗始终保留 Skill 名称、下载和关闭操作。桌面多文件包使用可折叠文件导航，手机在标题下使用 Kumo
文件选择器；单文件包隐藏两者。目录与正文独立滚动，弹窗保持在动态视口内。

Markdown 保留文档标题层级、合理行宽、GFM 列表和表格、行内代码及可滚动代码块。Frontmatter 可展开，源文件视图保留
完整 UTF-8 文本，包括 Frontmatter 和 BOM。包内链接打开实际包成员；当前文档的标题锚点滚动并聚焦对应标题。
脚本、HTML、SVG 及其他 UTF-8 文件显示为转义后的无高亮源文本。二进制、非 UTF-8 或超过 256 KiB 的文件明确提示
无法预览，仍可下载完整归档。空文件有明确状态。不提供编辑器、分享流程、文件执行或外部图片自动加载。

现有 Kumo 弹窗负责焦点约束和 Escape，关闭后仍保持挂载，焦点回到 Skill 详情入口按钮。包内链接在新内容加载后聚焦阅读区。
文件按钮和目录使用普通 Tab/Enter/Space 操作，采用导航列表而非需要额外键盘模型的 ARIA tree。
源文本、代码和表格滚动区支持键盘。切换 Agent 会卸载阅读器并取消请求。

## Account 文件读取接口

`GET /api/v1/agents/:agentId/skills/:skillId/file?path=SKILL.md&archiveSha256=<sha256>` 返回 JSON：

- `archiveSha256`：请求的内容版本；
- `path`：标准根目录相对路径；
- `files`：真实归档全部成员的路径和字节数，上限沿用 1,000 个成员；
- `preview`：`{ status: "text", content }`、`{ status: "binary" }` 或 `{ status: "too_large" }`。

接口复用 Account 所有权和精确 Agent/Skill 范围校验，拒绝已删除 Agent。所有者可以阅读已禁用 Skill。
不扩展 Computer 或 Session runtime 凭据接口。期望哈希与当前记录不符时，在读取存储前返回现有版本冲突错误。
缺失 Skill/文件使用现有 not-found 错误。响应使用 `Cache-Control: no-store`。

服务端在压缩大小上限内读取标准 tar.gz，校验实际长度和 SHA-256，并复用上传阅读器的路径、重复成员、链接、成员数、
解压后内容及 tar 流大小限制，不解压落盘。预览严格解码 UTF-8 并拒绝二进制控制字节；过大文件不静默截断。
完整目录来自同一份已验证归档，不依赖数据库中最多 500 个文件的管理摘要，无须数据库迁移。

共享 Zod schema 是请求和响应类型的来源。Web 查询键包括 Agent、Skill、期望哈希和路径；关闭阅读器后丢弃缓存正文。
并发替换会刷新列表并提示重新打开。暂时失败提供重试并保留文件导航。

每次请求一个文件都重新读取、验证有限大小的归档，避免新增解压文件存储或持久服务端缓存。
将来若增加缓存，必须保留内容哈希身份、Account 权限和相同验证限制。

## 渲染边界与验证

沿用现有 `react-markdown` 和 `remark-gfm`。跳过原始 HTML，中和不安全 URL，外部图片显示文字，包内图片进入明确的
不支持预览状态。仅 HTTP(S) 和 mailto 链接可在外部打开；未知相对链接保持无操作，避免导航到应用路由。
源文件作为 React 文本渲染，不执行。

单元测试使用真实 tar.gz，覆盖超过 500 成员的完整目录、权限、标准路径、旧哈希、损坏内容、解压限制、二进制/大文件/
空文本、Markdown 注入、文件导航和延迟 Agent 请求。浏览器证据与具体检查见
[UI 验证记录](../../../apps/web/docs/ui/skill-reader/README.md)。
